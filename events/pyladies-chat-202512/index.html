    在電商領域多年的資料工程師，目前專注於資料平台與後端系統開發。技術領域涵蓋 Data Pipeline（PySpark、Airflow、Web Crawling）、資料基礎架構設計（Data Infrastructure Design），也有帶領團隊的經驗。相信技術的價值不只在於解決問題，更在於幫助他人成長。除了開發工作之外，也長期投入技術教育與社群推廣，致力於降低學習門檻，讓更多人能夠透過程式設計解決實際問題。目前擔任 PyLadies Kaohsiung Organizer 與講師，負責 Python 入門工作坊設計與教學，並持續分享網路爬蟲、資料工程及資料相關技術知識，協助更多學習者建立實務能力。也曾擔任 PyLadies Taiwan Organizer、講師組組長與講師，參與社群經營、講師培育及工作坊設計。
